# Bookstore Management Application

This is an ASP.NET Core MVC project developed using ADO.NET and MS SQL Server.

## Project Objective

The objective of this project is to build a Bookstore Management Application where users can view, add, edit, and delete book records using ADO.NET database connectivity.

## Technologies Used

- ASP.NET Core MVC
- C#
- ADO.NET
- MS SQL Server
- Stored Procedures
- Visual Studio

## Features

- View all books
- Add a new book
- Edit book details
- Delete a book
- View book details
- Use SqlDataReader for connected architecture
- Use SqlDataAdapter, DataSet, and DataTable for disconnected architecture
- Use stored procedures for database operations
- Use parameterized queries to prevent SQL injection
